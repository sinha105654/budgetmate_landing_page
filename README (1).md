# BudgetMate AI: Landing Page

A single-page landing page for **BudgetMate AI**, an AI-powered budgeting assistant for young Australians.

Built for SIT726 (Deakin University), Task 6.2C, and updated for the Task 10.1D Innovation Showcase application.

**Author:** Yousuf Sinha (s226032987)

## What's in this page

- **Headline and supporting headline:** leads with the "forecast ahead, not just track behind" idea
- **Hero card:** an example ledger showing sample budget, spending and forecast data
- **Benefit summary:** a short pitch on why BudgetMate AI is different from typical budgeting apps
- **Call to action:** "Join the waitlist" (the waitlist is not live yet)
- **Feature benefits:** AI Budget Planner, AI Spending Forecast, AI Savings Coach and Type-to-log
- **Where we are today:** an honest status section (prototype built, validation interviews next, then a local beta)

## Design concept

The page is styled like a **checkbook ledger**: ruled lines, tabular numbers and receipt-style cards. This ties the visual design to the product's subject, budgeting, instead of using a generic app landing page template.

## Notes

- The ledger figures in the hero card are examples, not real user data.
- The working prototype and its code are in a separate repository: https://github.com/sinha105654/budgetmate-ai-8-2hd
